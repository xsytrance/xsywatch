# Promotional media — NOT Play screenshots

Wear OS quality requirement WO-G6 forbids device frames and any
text, graphics or background that is not part of the app interface
in a Play listing screenshot. Everything in this directory shows a
device frame or added composition and therefore may **not** be
uploaded as a screenshot. Play-compatible assets are in `../play/`.

`device_context.png` is a deliberately abstract dark body and
strap. It is not a photograph of any product and must not be used
to imply the watch is made of titanium, sapphire or gold — the
watch FACE depicts those materials; the device does not contain
them.
