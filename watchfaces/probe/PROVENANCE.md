# PROVENANCE — MERIDIAN PROBE

**Every asset here is original by construction.** No model, no prompt, no
external image, no reference art.

| Asset | Origin | Ships? |
|---|---|---|
| `pb_a` … `pb_z`, `pb_0` … `pb_9`, `pb_dot/colon/dash/slash/pct/query/space` | rendered from DejaVu Sans Bold by `tools/make_probe_assets.py` | yes |
| `pb_rose.png` | procedural — seeded drawing, same script | yes |
| `pb_needle.png` | procedural — seeded drawing, same script | yes |
| `pb_bg.png`, `preview.png` | procedural — baked labels, same script | yes |
| `watchface.xml` | generated by the same script | yes |

This is the only face in the MERIDIAN line with no generated-art debt. That
is not a design achievement — it is a plain instrument, and instruments are
cheap to draw. It is recorded because it makes the probe the one face in the
line that `docs/reports/AIRCRAFT_WATCH_DISCOVERY.md` would not block.

**It still should not ship**, for unrelated reasons: it is a dev instrument
with no design intent, `.dev` namespaced, debug-signed, and there is no
release configuration. Nobody wants to buy a table of integers.

## The font

DejaVu Sans Bold, from `/usr/share/fonts/truetype/dejavu/`, is **Bitstream
Vera / DejaVu licensed** — free to use, embed and redistribute, including the
rendered bitmaps here. See `THIRD_PARTY_NOTICES/`. The glyphs are rasterised
into PNGs at build time rather than embedded as a TTF, because custom TTFs do
not render in WFF on the Watch 7 — a pre-rendered `BitmapFont` is the only
route that works.

This is the collection's first bitmap font carrying **letters**. Every face
before it needed digits and a percent sign only, because every readout before
it was a number. `WEATHER.CONDITION_NAME` is words, and printing it is the
entire mechanism by which `WEATHER.CONDITION`'s integers get decoded.
