# MERIDIAN NIGHTGLASS

An original night-flight instrument watch face for Wear OS and Galaxy Watch 7.

- Smoked ceramic and sapphire avionics visual language
- Live battery, steps, heart rate, date, 24-hour time, temperature and rain
- Five native editor lighting themes
- Battery, heart-rate and Calendar shortcuts
- Sparse ambient/AOD presentation
- Zero permissions and no executable code

Generate with `python3 tools/nightglass/build.py`, validate with
`tools/wff_validate.sh 4 watchfaces/meridian-nightglass/app/src/main/res/raw/watchface.xml`,
and build with `tools/build_face.sh meridian-nightglass`.
