# Candidate renders (unapproved)

Proposed normal/AOD renders for a future visual version live here, one
directory per proposed version (first real use: `field-tourbillon-mk2/`,
Phase 3). Candidates:

- may exist and change freely without owner approval;
- are compared against approved goldens to MEASURE the intentional delta
  (the metrics land in the visual-change approval record);
- never replace anything under `goldens/` — promotion happens only through
  an `approvals/` record with owner status `approved`, validated by
  `tools/validate.py`.
