# Comparison masks

White (255) = compared, black (0) = ignored. Grayscale PNG, 480×480.

Masks exist ONLY for legitimately dynamic or non-capturable regions in
device-capture comparisons (e.g. the system charging-bolt overlay area at
12 o'clock when a capture had to be taken while docked). Deterministic
reference-render comparisons never use a mask — they require exact equality.

Policy (enforced by `tools/compare_visuals.py` and validation): a mask must
keep at least the `min_disc_coverage` fraction of the 480×480 face disc
(states.toml `[compare.mask_policy]`, currently 0.60) — a mask broad enough
to hide a WARBIRD-style substitution is itself a validation failure.

`device_status_overlay.png` — masks the top-center system indicator area
(charging bolt / connectivity icons One UI draws over the dial in some
captures). Generated by `tools/render_reference.py --make-default-masks`;
regeneration is deterministic.
